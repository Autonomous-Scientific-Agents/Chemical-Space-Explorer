# Agent traces

Archived AI coding sessions for this repository. Each folder has:
- a sanitized `session.jsonl`;
- an interactive `replay.html`, generated with the [ASA fork of claude-replay](https://github.com/Autonomous-Scientific-Agents/claude-replay);
- a `README.md` describing the task.

The replays (HTML only) are copied to `docs/agent-traces/` and published at https://autonomous-scientific-agents.github.io/Chemical-Universe/agent-traces/
